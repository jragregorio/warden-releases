# Warden releases

Windows installers for the Warden agent (parental screen-time control).

Download the latest `Warden-<version>-x64.msi` from the
[Releases](https://github.com/jragregorio/warden-releases/releases/latest) page,
or from **Download for Windows** in the parent dashboard.

Install on the child's PC as an administrator. After that, Warden updates itself
from inside the app when the child presses **Update**.

Each release lists the installer's SHA-256 so you can verify the download.
